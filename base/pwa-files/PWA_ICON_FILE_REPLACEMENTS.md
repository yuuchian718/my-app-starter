# PWA Icon File Replacements

## Purpose
This file lists the icon-related files and references that usually need replacement when creating a new project from this starter.

## Typical files to replace in a new project
- favicon files
- apple touch icon
- PWA icon images referenced by the manifest
- browser tab icon assets
- any project-specific generated icon set

## What usually stays unchanged
- general PWA wiring
- service worker example structure
- Vite PWA integration pattern
- non-icon base templates

## Quick verification checklist
- app icon displays correctly in browser tab
- app icon displays correctly in install prompt
- manifest icon paths are valid
- no old project icon assets remain
