# my-app-starter

A reusable starter kit for web apps, including PWA, trial system, UI language rules, docs, and Codex prompts.

## Structure

- `base/` shared starter foundation
- `modules/` optional reusable modules
- `docs/` implementation notes and checklists
- `prompts/` reusable Codex prompt templates

## Current contents

- PWA icon template
- PWA icon troubleshooting checklist

Planned modules:
- trial system
- UI language switch
- license system
- referral system
